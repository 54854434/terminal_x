## 接下来的主要架构改造（用户已授权大范围改写）

- **P0 机制：** 由一次 `nextTick()` 集中生成全分钟 NPC 交易，转为独立市场时间轴中的多次可审计挂单/撤单/逐笔撮合；真实连续形成 1m K、放量、影线，而不是插值动画。统一在每笔真实 Fill 写持久化游戏时间戳，兼容已有没秒级时间戳的历史。高倍速游戏时钟/经济事件调度与渲染解耦。
- **P0 性能：** 去除 `TxEngine.checkInvariants()` 每 Fill 反复遍历整份 Ledger 的 O(N²) 路径及每个 NPC 下单/撤单重复全审计的热点；采用事务级充分校验并保留提交前独立全量核对，不牺牲资产守恒。为 SQLite 构建原子追加事件、索引 K 线和检查点，减少完整历史快照写入/重启 64 次重复验证，仍支持旧 schema 1 只读核对与失败封闭迁移。
- **P1 跨市场：** A 股、美股、期货、外汇、加密五套市场规则共享订单簿/风险账簿，允许按真实复杂度推进；NPC 有有限资产/库存，报价冲击遵守成交；交易/资产/记录参考 OKX 和 Gate 的良好布局但不复制其品牌。
- **技术栈自由：** 用户允许改变 Flutter、Kotlin、Rust、C++ 等实现，但以 Android 手机实测 p50/p95、内存、体积和代码治理收益为依据，不为换语言而换语言；不同版本统一覆盖安装，旧数据绝不静默重置。

## 一、产品定位和开发权限

完全离线、Android 单人、无真实交易资金的虚拟金融市场交易游戏；以 A 股、美股、期货、外汇、加密货币五大市场为最终目标。玩法包括多资产资金管理、真实订单簿、独立规则、有限资金/库存 NPC、事件新闻、风险预算、滑点、费率/保证金/强平（需真实实现后才上线）。参考 OKX / Gate 的行情分析、K 线、盘口、订单、资产、记录页布局及交互密度，保留 Terminal X 深蓝黑、青绿 X 图标和独立品牌，不复制交易所素材。

**用户明确授予广泛研发自由：允许替换整个撮合引擎、SQLite schema、状态管理、Flutter UI，甚至技术栈；每版可同时大范围开发和性能治理，不被旧源码结构、旧路线图或补丁范围束缚。** 性能数据支持的 Kotlin/Jetpack Compose、Rust、C++ 混合方案可以采用，不为换语言而换语言。新的代码必须具备清晰职责和删除旧临时代码的退出条件。

唯一不能牺牲的硬条件：应用 ID `com.terminalx.game.terminal_x`、桌面名 `Terminal X`、同一私密正式签名、versionCode 递增、同应用覆盖升级、原有用户 SQLite/其他私有存档不被清空、所有资金/库存/流水/成交的账务审计、真实有限撮合、不伪造价量、离线运行。错误存档必须停止写入，不准自动建立空账户覆盖。

## 二、当前实机反馈（最高优先级）

V0.2.5 手机截图证实可运行至 60×、第 67 模拟分钟及 SQLite r74。用户持续反馈 **60× 下 K 线逐根闪现／加载，不像真实分钟内持续波动、很多 K 没有显著影线、仍有卡顿、冷启动较慢**。V0.2.6 已导入并生成 Release，但不能据此假定上述反馈已解决。

根因定位：

- `TxSession.nextTick()` 只在完整游戏分钟内集中撤单、挂单和 NPC 撮合；真实经济时钟还不是游戏秒级。即使 UI 高频刷新，也无从显示尚未成交的真实逐笔。**无影线不必然是 bug**：该分钟成交高低恰好是开收点时应没有影线；禁止用虚构成交价或无来源的高低价美化蜡烛。
- `TxEngine.checkInvariants()` 在大量 place/cancel 后全量扫描累计账务和成交；每个 Fill 还全量扫描账本匹配行，复杂度高。
- `TxSqliteStore.saveSession()` 每分钟完整存储累计订单+Fill+Ledger 的 JSON 快照。`readHistory(limit:64)` 冷启动反复解析并审计 64 个大快照。
- V0.2.6 将整分钟计算移入后台 Isolate，但完整 SQLite 审计、序列化和快照仍昂贵；数据库慢时游戏主动降速以保护账务，绝不补跳未提交分钟。

## 发布与手机验收

- 仅用**一个根目录** `terminal_x_batch.zip`，`manifest.json` schema=1，所有覆盖路径必须验证旧字节 SHA-256；CI 跑全部 `tx_*_test.dart`，签名 Release APK 构建成功后才提交新源码，并自动清理上传 ZIP。
- APK 保持 `com.terminalx.game.terminal_x` + 原 Secrets 的签名 + ARM64 输出；绝不卸载旧版、清空 SQLite、删除私有备份、迁移到另一应用 ID。仓库已有图标和中文直链 Releases 工作流，**无需再上传图标和 YAML**。`scripts/tx_release_notes_zh.md` 随本批 ZIP 更新。
- 本地没有 Dart/Flutter 编译环境，因此本包为**源码候选**，所有行为必须等 Actions 运行及用户实机确认。即便 CI 绿灯，也不可宣称高倍速卡顿/慢启动/秒级成交已修好。
- 真机合并验收：原 v0.2.7 私有 SQLite 覆盖恢复；分时→1m→5m→15m→1h→4h→1D切换；MA/缩放/拖动/点选 OHLCV；60× 和暂停下切页；存档关闭重启后历史不足提示；资金和成交量守恒；持续运行 240/1500 模拟分钟后的响应与数据库体积。
- 工作流本身如无更改就不需要再次编辑 `.github/workflows`；GitHub App 连接为 read-only，没有未经用户明确操作的 push 能力。
