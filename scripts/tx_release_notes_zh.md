# Terminal X v0.2.8｜多周期 K 线与分时图

**版本号：0.2.8+28**  
**平台：离线 Android ARM64 模拟交易游戏**

## 新增功能

- 行情页增加 **分时、1分钟、5分钟、15分钟、1小时、4小时、1游戏日** 七种查看模式，不需要额外联网行情。
- 新增分时折线：由已经提交的模拟分钟价格绘制，参考指示价与已成交价分开标识。
- 多周期 OHLCV 由已经提交的一分钟蜡烛聚合，真实最高价、最低价、成交量求和，不凭空生成价格路径和影线。
- 点击 K 线／分时图，可以查看对应区间的开盘、最高、最低、收盘和成交量。
- 多周期指标：MA5／MA10／MA20 随所选 K 周期计算；保留滑动历史和缩放功能。

## 性能与易用性

- 前台运行时的 K 线历史窗口由 160 根提升到 1500 根，满足更长游戏时间范围内的图表回看。
- 多周期数据和均线结果缓存；秒级提示价格更新不重复聚合所有 K 线。
- 对历史不足、缺失分钟以及尚未收盘的大周期明确提示，避免误把局部数据当作完整的 4小时或日 K 线。

## 已知限制

- 游戏引擎仍按整游戏分钟集中撮合，**本版没有实现真正秒级逐笔成交或连续形成的实盘式分钟 K 线**；60× 下蜡烛仍可能按秒出现。
- 大周期当前仅聚合可用分钟；应用重启后仍从最近 64 份 SQLite 快照恢复图表缓存，早期历史不会被本版凭空恢复。后续将采用可验证的增量历史表。
- SQLite 快照随历史增长、账务校验成本及长时间 60× 卡顿仍需要底层重构；无法保证完全消除。

## 安装说明

下载下方的 `.apk` 文件，直接覆盖安装已经安装的 Terminal X，不要卸载旧版或清除应用数据。若发生签名冲突，请停止而不是通过卸载绕过；私人 SQLite 和备份必须保留。

重构事件驱动的秒级真实撮合、增量存储、账务校验热点以及跨市场经济系统，逐步提供 A 股、美股、期货、外汇、加密货币统一操作体验。
