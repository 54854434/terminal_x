# Terminal X V0.2.9｜首批编译验证与 K 线缓存安全优化

版本：`0.2.9+29`｜离线 Android ARM64｜**源码候选，须 GitHub Actions 通过后才可能发布 APK。**

## 本批实际改动

- 改进已使用的 `TxLiveCandles`：同一分钟、无新真实成交、行情标记价未变化的账户订单修订，不再无意义重建 K 线；新模拟分钟仍生成真实的已提交 K 线。
- 严格拒绝成交历史回退，保持既有资金/冻结/订单/Fill/Ledger 和 SQLite schema 1 不变。
- 加入独立的高倍速帧时钟与暂停事务保护、基于已提交游戏分钟计算真实达成倍速、图表周期选择建议等模块与回归测试。
- **以上高倍速模块尚未接入正式主界面；本批不能声明已实现 100×、600× 或 3600× 可用。**
- 更新 `docs/TERMINAL_X_HANDOFF.md` 至 v7.0，记录真实开发进度、候选/生产区分以及 GitHub 编译交付流程。

## 继续保留的 V0.2.8 功能

分时/1m/5m/15m/1h/4h/1日 K 线、MA5/10/20、缩放/横向拖动、真实 OHLCV 聚合、最高 1500 根前台历史缓存、旧 SQLite 只校验恢复、不静默创建空账号。

## 未解决的问题

- 游戏经济事件仍在完整游戏分钟集中发生；参考指示价不是真实逐秒成交价。60× 可能卡顿，真实连续分钟内成交尚未完成。
- 增量 Journal 与多分钟交易批次暂未替换旧的整段 JSON SQLite 快照；应用重启后的较早 K 线仍受最近 64 份历史快照限制。
- 本地没有 Dart/Flutter SDK，本批需要 GitHub 导入工作流报告真实 Flutter 测试、ARM64 签名构建与签名证书结果。若 CI 失败，不要安装、不按成功发布计算进度。

## 安装及数据安全

只有确认 Actions 成功、APK 使用 V0.2.8 原有签名及同一 Android applicationId 后才可覆盖安装。**不得卸载旧版、清除应用数据或删除 SQLite 以绕过签名冲突**。覆盖安装前保留用户私有备份。
