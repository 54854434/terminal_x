# Terminal X v0.3.0

## R31 性能专项（不增加玩法）

- 采用常驻市场 Isolate：同一个后台市场会话连续完成分钟推进及玩家委托，减少重复创建短生命周期 Isolate 和 UI→后台的完整对象图传递。只有数据库提交成功才更新屏幕可见状态；失败直接丢弃未提交工作状态。
- 交易撮合/账本采用易失性经济变更版本标记：每分钟仍执行一次完整账本审计，已审计且未再次改变的候选不再在存档准备阶段重复做完整历史校验。
- 新快照直接对已审计的类型安全候选编码，移除每分钟完整 JSON 导出→导入→再导出的冗余循环。TXD1 仍重放并与规范完整结果校对，旧 JSON/TXZ1 继续可读。
- SQLite 元数据表添加轻量的已提交 K 线只读索引，开机优先读取已绑定修订号/哈希的近期行情，缓存过期或损坏时回退现有完整历史恢复逻辑。索引不包含真实账户余额或可执行价格。
- 同步加入取消委托、冻资、持久工作线程、异常状态重新同步、增量确认游标和缓存回退等回归测试；附设备实际平均/p50/p95 分钟提交耗时的对照脚本 `scripts/tx_r31_perf_benchmark.dart`。
- 继承 R30 活动订单索引、R29 增量变更追踪、R28 1–64 次可调完整检查点、R27 增量快照以及全周期逐帧 K 线。

### 安全及限制

- 旧账号、持仓、冻结资金、真实成交和旧 schema 1 存档均保留。交易一分钟及每次下单/撤单依旧需要 SQLite 原子提交。
- TXD1 新快照仍不适用于旧 APK 降级读取；升级前应备份，不能删除已有账号数据。
- 完整历史账本仍会在交易边界执行一次全面审计，旧快照仍永久保存；本轮未更换 Rust/C++ 或自动归档删除历史。
- 本批次本地可核对 ZIP CRC、manifest、SHA-256 和源代码静态约束，但当前无 Dart/Flutter SDK；Flutter 回归、ARM64 Release 签名、Android 实机性能均待 GitHub Actions 验证，不声称已经达到特定倍速。
