# Terminal X v0.2.7｜后台交易操作与成交事件基础

**版本号：0.2.7+27**  
**平台：Android ARM64，离线模拟交易游戏**

## 本次更新

- 将玩家下单、撤单时的会话复制与账务模拟移入后台 Dart Isolate，减少同步 JSON 处理阻塞 Flutter 画面的机会。
- 新增仅以引擎实际撮合成交（Fill）为来源的增量交易事件序列；保留真实成交数量和价格，禁止补造成交量。
- 为连续市场事件引擎增加纯成交 OHLCV 聚合基础，事件顺序可重放，但旧成交尚未记录精确游戏秒，不会伪造时间戳。
- 增加并发操作、撤单资金释放、成交事件一致性测试，保留既有 SQLite schema、应用包名、Release 签名与图标。

## 当前仍未解决的问题

- K 线目前仍按完整游戏分钟落账并显示；**本版尚未实现真正秒级撮合或分钟内连续形成的 K 线**。
- 高倍速长时间运行依然受账本反复审计和每分钟完整 SQLite 快照增长影响。
- 部分 K 线没有上下影线可能是该分钟价格路径及真实成交所致，不会为了好看伪造影线。

## 安装及存档

下载本页下方的 `.apk`，直接覆盖安装已安装的 Terminal X。**不要卸载旧版本或清除应用数据**。如提示签名冲突，请停止，不要通过卸载绕过。旧版私有存档原样保留；是否覆盖升级成功需以手机验证为准。

## 后续开发

优先重构市场事件调度、账务审计复杂度、SQLite 事件/检查点存储，再将真实逐笔与实时 K 线连接。五市场与 OKX/Gate 风格 UI 的目标保持不变。
